# Item Inventory Management System
This is a Capstone 1 project repository.

A React + Vite app for tracking IT equipment inventory (add/edit/delete items, search, status stats). Equipment data is stored in PostgreSQL. Only admin users have the privilige to change what is in the inventory (add/edit/delete items, search, status). Non-admin users are only granted to search equipments and see the current status of the available equipments. 

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```
